# 📚 Book Recommendation System

This project is a simple yet effective Book Recommendation System built using machine learning techniques. It helps users discover books similar to a given book title based on content similarity.

---

## 📌 Project Highlights

- ✅ Used cosine similarity to recommend similar books
- ✅ Built with Python, Pandas, and Scikit-learn
- ✅ Trained on a real-world dataset of books
- ✅ Interactive notebook for easy understanding
